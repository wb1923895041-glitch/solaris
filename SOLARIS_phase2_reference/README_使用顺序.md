# SOLARIS 第 2 期素材包说明

## 文件与用途

- `太阳与八大行星_高精度视觉资产_Codex提示词.md`：本期唯一的 Codex 执行清单。以实际文件名为准。
- `reference/01_SUN_独立基准.png`：太阳光球、日珥、活动区的**生成式美术参考图**；请注意其戏剧化视觉不代表实际某日的观测。
- `reference/02_九天体资产总览参考.png`：各天体视觉差异与 UI 质感参考；图中数值可能不准确，不能用于计算，也不能把面板裁切后作为贴图。

## 科学责任边界

生成图不是球面纹理、无 equirectangular 投影与经纬度/方位约束，亦不代表有确定日期的可观测外观。正式天体纹理需从 NASA/JPL/USGS/ESA 等可靠来源逐个核验下载。对增强色影像须注明；云层、风暴、太阳活动不代表任意时间都真实。
