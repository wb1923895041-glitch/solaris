# SOLARIS｜第 2 期：太阳与八大行星高精度视觉资产

> **执行对象：Codex；只执行本期，不进入卫星、小行星带、物理实验室。** 目标平台 Windows Chrome/Edge，桌面端优先，基准分辨率 2560×1440，4K 高画质可选。

## 0. 唯一目标与边界

在第 1 期已验收的真实太阳系总览、JPL 星历、时间系统、参考坐标系、相机和比例模式之上，升级**太阳 + 八大行星的材质、几何、光照、渲染和特写体验**，做成高质量数字天文馆。**不是重构轨道，不是新建项目，不是把概念图贴到球上**。

开始前先检查真实仓库：列出已完成的天体渲染模块、shader、纹理资产、加载器、场景管理、画质配置、视频截图测试、材质版本；创建可恢复 Git checkpoint。已有达标能力复用；未做完的第 1 期科学基础不应偷偷用伪数据补齐。列出原问题，先建立基线截图与性能报告。

严格冻结：
- 轨道/历表/速度/日期/参考系的科学计算结果；所有天体的世界坐标与公转不因材质改变。
- 科学比例模式的**真实半径与距离使用同一线性换算**；探索比例只能作为明确标注的展示变换。
- 已实现的 PC 交互、鼠标拾取、相机轨迹、选中状态、导航、时间播放和数据面板。
- 本期不新增完整卫星/小行星带、冥王星、彗星和 N 体模拟，不把原项目功能清空。

如第 1 期未完成，明确报告缺项，并在不造假的前提下只完成材质工作，不能假报第 1 期通过。

## 1. 真伪层分离——必须有 Asset Provenance

明确区分：

1. **科学数据**：行星半径、倾角、位置、自转、参考坐标系、轴向定义及时代对应的经度使用有来源的数据。
2. **观测与贴图**：表面/大气图来自 NASA/JPL/USGS/ESA 等可核验来源，包含原始图名、任务或仪器、网址、制作者、授权、颜色处理、地图投影、经度方向、成像时间/合成时间、分辨率；第三方版权材料需遵守授权。
3. **科学重建**：不可被整球真实影像覆盖的区域，可依照观测资料重建。必须标注 `RECONSTRUCTED`，不得称逐像素真实照片。
4. **视觉特效**：Bloom、曝光、日冕、夜侧增强、星光光晕等仅为观察效果，须与物理位置和可验证数值解耦。标注 `VISUAL_ENHANCEMENT`。
5. **本包概念图**：只用于艺术方向、画面密度、分层结构；图中文字与数值未经验证，不能摘抄，不能裁切作为行星 equirectangular 贴图，也不能作为星历。

建立 `public/assets/celestial/manifest.json`（实际路径根据仓库调整），每个对象：

```ts
type AssetSource = {
  sourceUrl: string; provider: string; title: string;
  acquisitionDate: string; observationEpoch?: string;
  processing: 'natural-color'|'approx-natural-color'|'enhanced-color'|'false-color'|'reconstruction';
  rights: string; credit: string; licenseNotes?: string;
  projection?: 'equirectangular'|'cubemap'|'procedural'|'not-applicable';
  longitudeConvention?: 'east-positive'|'west-positive';
  primeMeridianOrOrientationNotes?: string;
};
type BodyVisualManifest = {
  bodyId: string; albedo?: AssetSource; normal?: AssetSource;
  roughness?: AssetSource; clouds?: AssetSource;
  night?: AssetSource; ringOpacity?: AssetSource;
  referenceLinks: string[]; visualEnhancements: string[];
  hasVerifiedOrientation: boolean;
};
```

NASA 影像通常可以按其媒体使用指南用于科普，但仍要核对每项具体素材是否含第三方版权，不得宣称 NASA 对本项目背书。 https://www.nasa.gov/nasa-brand-center/images-and-media/

优先查找：
- https://science.nasa.gov/solar-system/
- https://svs.gsfc.nasa.gov/
- https://nssdc.gsfc.nasa.gov/planetary/planetfact.html
- https://pds.nasa.gov/
- https://astrogeology.usgs.gov/
- https://photojournal.jpl.nasa.gov/

**请实际检索、记录并核验素材，不要直接编造贴图下载 URL。** 某素材无法授权或无法确认投影时，用明确标记的程序化占位实现，不要冒充高精度真实资产。

## 2. 视觉风格与画面门槛

风格为：NASA 数字天文馆 × 现代科学可视化 × 克制的电影摄影，不是霓虹星球游戏。黑色深空、真实太阳单向光、清晰的昼夜分界、材质层次、有识别度的颜色和纹理、无多余装饰。

展示分辨率：默认 2560×1440、1920×1080 适配、3840×2160 高画质检查。视角提供全局总览、天体标准三分之二视角、晨昏线特写和背光边缘；每颗行星必须有独立可交付截图。

不得出现：
- 所有行星共用一张随机噪声贴图、发光水晶球或统一金属 PBR 材质；
- 木星/土星表面像岩石或有真实固体地表；
- 金星在默认可见光模式下看得见表面纹理；
- 天王星拥有不合理浓厚的土星式明亮光环；
- 海王星全天候夸张的霓虹蓝、固定风暴；
- 地球白云跟随地表一体旋转、双重照明、夜面自发蓝光；
- 漫反射与贴图色彩重复乘色、sRGB 错误、反射高光塑料感；
- 为了视觉构图更改真实的大小、轴倾角、位置和时间。

## 3. 九个天体的独立资产制作与验收

每个天体都有专属独立材质配置、独立的视觉参考说明、LOD 级别与特写截图。以下参数为**美术方向与实现要求**，所有物理数值由已验证数据加载器提供。

### A01 太阳 Sun（恒星，不属于八大行星）

**视觉基准**：本包 `references/01_SUN_独立基准.png`。光球的米粒组织、分布不均的暗部活动区、边缘加深与极薄的发光晕；日珥与日冕须以可开关的增强效果呈现。太阳不是一颗橙色岩浆行星，也没有火焰燃烧；生成图过度戏剧化的部分需要克制修正。

实现层：
- 辐射自发光球体与场景中的物理启发式光源分离；近处高亮光球显示保留高光细节；HDR tone mapping 保证曝光不炸白。
- 光球纹理层、程序化细尺度扰动、可选活动区遮罩、低强度 corona shader、可关闭的日珥活动图层；不能宣称日珥的某一时刻形状真实。
- 对太阳表面纹理的运动可作艺术化表现；若要描述太阳差异自转为严格模拟，必须独立引用数据而非固定一圈转速。
- 跨远近距离维持良好的亮度视觉等级，不靠半径膨胀作弊。
- 切换太阳光源需要不破坏行星的实际太阳方向与阴影。

验收图：`sun_full.png`, `sun_limb.png`, `sun_surface.png`；并提供有/无增强效果对比。

### A02 水星 Mercury

**视觉基准**：灰褐岩石、极密集撞击坑、明亮喷射纹与大型盆地，切忌把它做成月球复制粘贴。

- 使用 Messenger 等真实观测的全球地形/色彩图；记录增强色或近自然色，默认尽量采用近自然色。
- 法线/高度细节仅在有数据支持的尺度使用，不随机生成巨型沟壑。
- 几乎没有可见的厚大气层，不得添加地球式蓝色边缘。
- 背光侧主要是黑暗，不做自发光裂纹。

验收：标准视角、撞击坑近景、夜半球。

### A03 金星 Venus

**视觉基准**：不透明的淡黄白色厚云层、柔和云带、大气散射，球体不应是棕色沙漠。

- 默认**可见光观察**时以云顶为主；将雷达地表数据放进“雷达/地形图模式”，并明确不是人眼可见表面。
- 云层漫反射、低对比旋涡、浓厚大气边缘；不应使用高速随机旋转纹理冒充真实超级自转。
- 在昼夜边界与逆光下正确处理散射。

验收：云层全貌、逆光边缘、可见光/雷达模式对照。

### A04 地球 Earth

**视觉基准**：NASA Blue Marble 等近自然色地表、独立半透明云层、真实日照方向、城市灯光仅在夜面可选显示。

- 地表反照率/法线，海洋粗糙度与有限的镜面反射；不把海洋做成大面积金属镜子。
- 云层单独球壳、透明/阴影排序正确，移动与自转分离；云图纹理的时间有效性必须标注。
- 大气散射薄而克制：蓝边不宜超过地球半径不合理比例；支持开启/关闭以观察本体。
- 昼夜与城市灯光方向准确，不能夜面完全亮起；城市灯光仅是贴图与演示，不是所选历史日期的实时灯光数据。
- 自转、黄赤交角、季节方向继承科学坐标模块；至少验证两个不同日期的太阳照射方向。

验收：晨昏线、完整日照、云层剥离模式、夜面、季节变化。

### A05 火星 Mars

**视觉基准**：低饱和铁锈红土、暗色地表、极冠、峡谷/火山差异，不能是一颗橙红色光滑塑料球。

- 使用 NASA/MOLA 或适当测绘/影像构建 albedo 和 normal/bump；火星高程应对应真实地形。
- 限制地形高度的可视化夸张，必须可关闭；不要将大气做成地球式厚层。
- 薄薄的金橘色大气薄雾，默认低强度；沙尘暴可作为附加科普模式，不默认全年覆盖。

验收：全球全貌、典型区域近景、极冠和晨昏线。

### A06 木星 Jupiter

**视觉基准**：低纬和高纬带状云系、白色和橘褐色云带、自然色大红斑；高分辨率云顶层，不能是固体星球。

- 使用来自 Juno/Cassini/Hubble 的观测资料；记录观测日期和色彩处理。
- 大红斑位置与形状属于某个成像时间的快照，不能宣称在任意历史日期都准确。提供“参考纹理历元”的说明。
- 可使用多层 shader 丰富纹理，但禁止没有依据的夸张流体旋涡和与真实云带矛盾的方向。
- 木星没有可见固体表面；镜头不得进入伪造地表。

验收：标准全貌、大红斑特写、无高光塑料感的半球。

### A07 土星 Saturn

**视觉基准**：淡金米黄色气体云带 + 细薄、层次丰富、半透明的环系；土星环不能是一块实体金属圆盘。

- 球体云带精细但比木星对比度弱；光照接近自然色。
- 环：至少具备 A、B、C 环的不同反射与光学厚度、卡西尼缝（Cassini Division）清楚可辨；用径向纹理/实例化实现，光从环上方照射，环对行星的阴影与行星投向环的阴影在技术允许范围内正确。
- 轨道/自转坐标继承阶段 1，环法向与行星赤道一致；观测视角随实际几何改变倾斜。
- 环的光度可以增强帮助科普，但必须标注增强；主环详细科研结构可留在卫星环系阶段进一步细化。

验收：正面、侧面、逆光、卡西尼缝与阴影局部图。

### A08 天王星 Uranus

**视觉基准**：低饱和青绿色、非常细微的云顶结构与淡薄光环，不是纯蓝玻璃球。

- 轴倾角极大，必须正确表达“躺着转”的轴向，不允许为了摆拍改轴。
- 云顶应低对比；特殊观测波段的夸张色彩必须标注伪彩。
- 微弱细环可以保留简化版，但不能喧宾夺主；精细环系交给后续阶段。

验收：全貌、轴倾角视图、若显示环则附视觉增强说明。

### A09 海王星 Neptune

**视觉基准**：偏深蓝的大气、细微云带、少量高空白云，避免纯电光蓝和永久巨型暗斑。

- 默认近自然色，不将某次增强色影像作为默认自然外观。
- 动态云层可以表现，但不能把示意的风暴位置当成历史真实预测。
- 细微大气边缘与对比控制，夜面跟随太阳方向变暗。

验收：全貌、云细节特写、背光边缘。

## 4. 核心技术实现

### 4.1 渲染与材质层

- 统一 `CelestialVisualSystem`，包含 `CelestialBodyVisual`, `AtmosphereLayer`, `CloudLayer`, `RingLayer`, `SolarPhotosphere` 等可复用但不强制共享所有 Shader 的模块。
- 每个天体单独 `BodyVisualConfig`：可用贴图、色彩空间、颜色空间转换、BRDF 参数、光照系数、增强层开关、LOD 阈值、材质版本、资产来源。
- 材质组件与星历计算模块隔离：材质消费已验证世界变换和相机参数，**不得重算轨道**。
- 使用经过验证的物理启发式可见光渲染；除非实现了严格辐射传输，不要宣传为完全物理精确的辐射模拟。
- 纹理颜色（反照率）使用 sRGB、normal/roughness/height 使用线性数据通道。验证法线方向、UV 方向、equirectangular 经线接缝与球体法线。
- 深空背景不对行星夜侧提供未经声明的强环境补光；极弱艺术化补光须可关闭。

### 4.2 光照、曝光、阴影

- 光源方向根据天体相对太阳的**真实位置**实时计算。
- 统一 HDR tone mapping / exposure 控制，避免太阳不炸白却把外行星曝光压成不可见；允许观察体验自动曝光，但必须注明属于视觉观察增强，不改变亮度物理事实。
- 行星昼夜线必须和第 1 期太阳方位一致；日照与轴倾角不可被摄像机位置决定。
- 土星环投影/自遮挡为重点；未来卫星日食留到卫星阶段。

### 4.3 远近精度、纹理流与画质

- 高画质优先；按屏幕像素直径选择 LOD 与纹理分辨率，避免远处读取 8K 贴图。
- 建议 2K / 4K / 8K（根据真实源图与显存预算）；不得将低分辨率图像简单插值到 8K 并宣称高清。
- 图片压缩可以 KTX2/Basis、mipmaps；用真实帧时间、GPU 内存和纹理加载时间制定策略。
- 避免材质重复编译、重复加载、texture dispose 后引用、页面切换显存泄漏、距离变化时闪烁和 LOD 跳变。
- 测试默认 2560×1440 + 1920×1080；4K 是高质量档可选。

### 4.4 相机细节与 UI

- 首次聚焦任一行星，0.8–2.5 秒内平滑接近至合适观测距离（非强制固定时长），不穿模、不裁切、不出现不合理超近景。
- 鼠标可以绕天体旋转、拉近到显示细节、观察其晨昏线、回到太阳系。
- 可选工具：大气层开关、云层开关、夜面增强开关、表面/贴图类型说明、来源查询、标准视角快速恢复。
- 这些是**材质观察开关**，不改变天体物理状态。
- 不要增加一堆默认展开的功能按钮破坏总览；高级观察控制放置于行星详情的二级面板。

## 6. 科学与视觉验收（必须实际执行）

**科学不回归**：
1. 第 1 期轨道/位置/时间测试必须继续全部通过；物理状态数据与资产改造前一致。
2. 对任一测试日期，行星昼夜分界的光照方向与太阳向量一致。
3. 地球/天王星自转轴方向和土星环平面与参考姿态一致。
4. 所有颜色处理、真实影像/重建/增强状态可查到 manifest。
5. 金星可见光模式不裸露地表；木星/土星无虚构固体表面；各行星不互相复制纹理。

**视觉验收**：
1. 太阳 + 八大行星分别生成一张独立 2560×1440 标准特写；画面内的主体足够清晰。
2. 每个岩石行星至少一张纹理细节特写；气体/冰巨星至少一张云带特写；太阳三张特写，土星环四张。
3. 展示至少一个地球晨昏线正确、太阳照明侧改变的时间对比视频；不能手动转动照明灯偷换效果。
4. 每颗行星提供原项目与改造后的同相机、同时间、同画质对照。
5. 不以“看起来像”替代源图与姿态测试。

**性能与工程验收**：
- 第 1 期的视角、时间、鼠标拾取、浏览器刷新、刷新后状态恢复正常。
- 2560×1440 高画质在明确记录的硬件上尽量达到 60 FPS（性能依具体 GPU 而定），报告 P50/P95 帧时间；不得无依据保证所有设备 60 FPS。
- 4K 画质可接受为更高硬件要求，提供真实设备及测试结果。
- 执行项目原有 TypeScript typecheck、lint、unit/e2e/visual regression，记录准确命令和通过/失败摘要。
- 确认无 WebGL errors、资源 404、可见纹理接缝、闪烁或内存持续增长。

## 7. 交付与停机边界
