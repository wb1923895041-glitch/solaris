## 使用优先级
1. NASA/JPL/IAU 等可追溯科学数据决定数值、坐标、轨道、分类和真实天体外观。
2. 基准图仅决定布局、材质品质、灯光氛围、镜头语言和 UI 设计方向。
3. 图片为生成式概念设计，可能存在文字错误、数字错误、轨道布局不真实、尺寸和距离非比例、天体数量不完整。**严禁从图中抄录科学数据、贴图或轨道。**
4. 概念图中的小行星密集程度属于视觉示意；实际小行星带应稀疏，真实数据点与统计采样必须分别标识。
5. 土星环、天王星环、太阳日冕等需按科学资料构建；增强可见度必须标注。
6. 图片不能直接作为球面 equirectangular 贴图。球面资产必须使用有出处的 2:1 经纬度纹理或科学影像制作的专用纹理，配合法线、粗糙度和大气层等。

## 每期验收
- 先完成一个最小可运行、可验证切片，再拓展规模。
- 截图需和基准图比较：构图、色彩、细节、清晰度、空间层次、文字可读性。
- 科学数值独立和 JPL 历表核验，视觉截图不能代替计算测试。
- 项目只做 PC，主设计 2560x1440，测试 1920x1080 和 3840x2160。
