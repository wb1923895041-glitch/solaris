Phobos and Deimos Shape Models Derived from Ernst et al. 2023

Phobos Global Shape Models

This version of the Phobos shape model has been shifted to eliminate any COM-COF offset. It has also been migrated from PCK00010 to PCK00011. In addition, the maplets were iterated a total of ten times, which improved the quality of the topography.

Phobos Regional DTMs

The regional Phobos DTMs have a 10-m ground-sample distance, so they fully represent the topographic detail in the v004 shape model. They are grouped into 3 zip files based on latitude. Each zip file contains many regional DTMs in FITS format. The colorings exist as additional planes in the FITS files. The label file lists the bigmaps contained in each zip file.

Regional DTM File Name Description Shape Coloring Label
phobos_north_latitude.tar.gz Zip file containing the regional DTMs centered ≥30ºN. shape label
phobos_mid_latitude.tar.gz Zip file containing the regional DTMs centered <30º from the equator. shape label
phobos_south_latitude.tar.gz Zip file containing the regional DTMs centered ≥30ºS. shape label
