## 科学状态、真实来源与观察增强

天体继续采用 JPL Horizons 的本体中心状态，原始参考为 SSB / ICRF / km、km/s / TDB；显示时在相同历元同时减去太阳位置与速度。探索映射、尺寸增益和科学比例沿用既有定义。近期轨迹是历表路径，不是即时轨道根数：取当前时刻前后约半个目录平均公转周期，并向采样端点取整、裁剪至 2024–2031 年星历窗；水星每天、金星和地球每两天、其余每四天采样。外行星只能得到不完整弧段，不强行闭合。历史档显示全部缓存路径，不能解读为单一时刻的密切轨道。

星空来源：[NASA SVS Deep Star Maps 2020](https://svs.gsfc.nasa.gov/4851/)，署名 NASA/GSFC SVS / Ernie Wright。原始 4096×2048 EXR 保存在 `data/overview-repair/`；来源页快照、原图和派生纹理 SHA-256 均可核验。ICRF 方向通过原冻结变换转入显示坐标；赤经 0 居中、赤经向左增加。HDR 经 `1-exp(-0.65*HDR)` 压缩并编码为 sRGB，运行时线性增益 0.18，沿用 ACES 曝光 1.15。它是恒星目录背景，不随当前日期传播恒星自行，也没有逐星识别或测光精度保证。没有裁剪附件概念图作为纹理。

太阳影像仍为 NASA/SDO HMI **2025-09-07 00:00 UTC** 光球快照，非当前太阳天气；背面镜像重建、JPEG 缺少完整 WCS，绝对日面经度配准未验证。原图和重建范围见太阳 `config.json`。暖色、日珥与分析式日冕属于可关闭的观察增强；本轮日冕壳为 1.18R、峰值 alpha 0.14，无 Bloom，不是观测到的日冕轮廓。

## 实际测试与误差

- `npm run build`：TypeScript 和 Vite 构建通过；存在 >500KB chunk 提示。仓库无独立 lint 命令。

- `npm run check:contracts`：15 项通过；冻结检查 59 文件不变。
- Chrome **155.0.8059.85**：24 项；Edge **156.0.4314.50**：23 项。三分辨率布局、9 天体/8 轨迹、轨迹切换、播放期间静态顶点版本、科学/探索切换、日期边界、实际拖动/滚轮、地球 Hero 回归通过；控制台异常及失败资源均为 0。
- 最新构建额外完成 Chrome/Edge 冒烟检查：总览、纵深导航选中状态、返回总览及太阳 4096 纹理通过，补拍文件名含 `final`。完整性能测试和视频在仅有导航选中样式、来源文案及诊断样本字段调整前采集，未将其伪称为最新构建重新测得的性能。
- 独立 Python 从冻结 F64 文件另行执行 Hermite 插值、太阳质心相减和显示映射，对比实际浏览器 high+low 顶点：2 个比例 × 3 个日期 × 8 条路径 × 4 个采样，共 **192** 例，最大重建差 **1.13769×10⁻¹² 场景单位**。这衡量缓冲重建，不是 JPL 位置误差，也不测量曲线采样间的视觉弦差或 GPU 栅格误差。
