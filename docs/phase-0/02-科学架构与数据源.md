# 科学架构冻结 v0.1

冻结日期：2026-10-29。这里冻结接口和处理规则；数据适用时间、实际误差和天体参数尚未取得，不宣称科学引擎已实现。

## 单向数据路径

```text
官方来源 → 原始响应/内核快照 + 查询参数 + 哈希
        → 导入校验 → 单位/时间/参考系规范化 → 只读 EphemerisStore
        → 所选 TDB 时刻的插值/采样 → DisplayPolicy → 相机相对坐标 → GPU

只读真实状态 → 显式复制初始条件 → ExperimentStore → 独立积分器
```

真实星历、展示、实验采用不同类型、缓存键和写权限。展示策略不得写回 EphemerisStore；实验必须显示“假设实验”。实验状态无论数值多接近真实状态，都不能进入真实星历导入接口。第 0 期只声明接口，无这些存储或转换实现。

## 时间、空间、单位

1. 计算时间使用 TDB，自 J2000 TDB（JD 2451545.0）的秒数，使用 JS number / Float64Array。输入与显示 UTC；禁止用 `Date` 毫秒加固定偏移冒充 TDB。第 1 期采用经核验的 SPICE 转换工具链，保留 LSK 文件名/哈希及转换版本。闰秒、历史 UT1、未知未来闰秒须单独处理；UI 不承诺任意年代的 UTC 精度。[SPICE 时间文档](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/time.html)
2. 规范化状态原点为太阳系质心（NAIF ID 0），坐标轴 ICRF，参考平面 FRAME，几何状态 NONE，不使用光行时修正。ICRF 不能与“J2000 黄道面”混称。显示总览的黄道倾斜作为单独相机旋转，并保存变换矩阵。[Horizons 手册](https://ssd.jpl.nasa.gov/horizons/manual.html)
3. 位置 km、速度 km/s、半径 km、质量 kg、GM km³/s²，角度 rad，周期 s。原单位与原字段保留在原始快照；不把平均距离当实时距离，不把半径当直径，不把系统 GM 当行星本体 GM。科学数值都附 `unit`、来源、处理链与不确定度；未知值 `null`，未知不确定度显式标注 unknown。
4. AU 换算须使用 IAU 2012 B2 的精确定义；实现阶段从独立有来源的常量表读入，本期不写入天体数值。[IAU 单位说明](https://iauarchive.eso.org/public/themes/measuring/)
5. 行星“中心”与“系统质心”不可互换；请求前逐个核对目标 ID 与回包名称。主行星按本体中心建立渲染目标，轨道计算保持明确 ID。卫星局部状态只有同一时刻、参考轴、单位、修正类型才可相加，转换路径及母体状态都进入溯源。缺失偏移时拒绝转换。

## 导入边界与可复现性

`EphemerisState` 与 JSON Schema 约束规范化样本。导入器还必须核对：sourceId 在登记表；URL 属于对应来源；SHA 匹配原文件；数值有限；向量三维；start ≤ epoch ≤ end；目标/中心与原始头一致。JSON Schema 仅做结构检查，不能证明来源真实或数值准确。

缓存键冻结为 `(provider, target, center, frame, referencePlane, correction, timeScale, units, coverage, sampleStep, solutionVersion, sourceSha, interpolatorVersion)`。保存原始响应与完整查询，无凭据。失败、覆盖外、解析异常必须显示缺失，禁止随机轨道或静默二体回退。插值采用位置/速度约束的分段方法，采样间隔经目标专属误差门限确定；跨分段与跨版本禁止直接拼接。

Horizons 第 1 期查询模板：`EPHEM_TYPE=VECTORS, CENTER=500@0, REF_SYSTEM=ICRF, REF_PLANE=FRAME, VEC_CORR=NONE, OUT_UNITS=KM-S, TIME_TYPE=TDB, VEC_TABLE=2`；COMMAND、起止和步长按目标验证后填入。API 的 JSON 包装包含文本表，须校验头和 `$$SOE/$$EOE`，不能将整包当纯数值 JSON。

## 展示映射冻结

- 科学比例：`renderPosition = R × (positionKm − cameraKm) / kmPerRenderUnit`；半径也用同一 kmPerRenderUnit。CPU 先做双精度减法，再传 GPU。不可为了可见度偷偷放大半径；可用明确区分于几何的屏幕标记。
- 探索比例：以所选焦点为锚，距离采用 `r' = L·log1p(r/r0)`，方向保持，半径为独立展示增益。L/r0/增益均属渲染配置并显示标识。屏幕标尺给出反函数 `r=r0·expm1(r'/L)`；非线性变换不用于物理、日食预测或科学量测。
- 局部系统：以指定行星中心/质心为锚，尺寸与距离统一线性比例，按视场选择比例，不改源状态。
- 本期三个模式不实现，仅在 UI 告知后续接入。参数值留给第 1/3 期实际场景验证，当前没有虚构的放大倍数。

## 独立实验室与带状粒子

第 6 期才实现 Newton 引力与 Velocity Verlet/Leapfrog；固定物理步长、可复现初值、子步进、能量与角动量漂移；碰撞与近距离事件暂停并告警，不能通过画面平滑掩盖发散。引力常量及质量均有单位来源，零能量/零角动量初值采用绝对误差以免除零。

第 4 期统计带使用独立 `illustrative-population` 层与确定随机种子，标注示意，不拥有真实目标 ID。不用均匀圆环模拟真实分布；倾角、偏心率与共振缺口依据样本和文献确定。与真实命名小行星分开查询和显示。
