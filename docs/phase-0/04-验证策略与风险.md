实际命令与结果以 `verification.txt`、`browser-checks.json` 和验收索引为准。构建成功只能证明工程可打包；契约检查只能证明测试反例被拒绝；截图只能证明空场景画面。当前没有导入科学状态，km/AU 位置误差 **不适用，尚未测量**。没有正式纹理或真实太阳系负载，FPS **未评估**。

## 后续科学验证计划（未执行）

| 对象 | 方法 | 计划门限/失败行为 |
| --- | --- | --- |
| 原始状态解析 | 同一解版本、同一时刻/中心/轴/修正与 JPL 原样样本逐分量比对 | 规范化往返 ≤1e-6 km、≤1e-10 km/s；超过拒绝导入；非天文学精度声明 |
| 时间 | SPICE 对照；J2000、2000闰年、2016-12-31闰秒前中后、时间覆盖边界 | 转换往返 ≤1 ms；不能表示的闰秒输入显式拒绝；未来未知闰秒提示 |
| 多日期星历 | 计划 2000-01-01、2024-01-01、2026-10-29、2030-01-01；只在覆盖交集内，日期使用明确 TDB epoch | 行星插值误差目标≤10 km，主要卫星≤1 km；超标细分采样，仍失败则禁用区间 |
| 比对报告 | 记录每对象/时刻 max/RMS、km/AU、速度误差、源 SHA、完整查询、有效覆盖 | 同源插值比对不代表独立物理真值；另以匹配内核 SPICE 对照转换路径 |
| 中心变换 | 地月、火卫、木星四大、土卫、冥王星-卡戎；路径相加与直接状态对照 | 误差不超过相关源/插值预算；不得把木星系统质心当木星中心 |
| 展示隔离 | 各比例切换前后源状态 SHA/数组对照；探索映射反函数、r=0边界 | 不写源状态；科学比例半径/距离同比例；探索模式始终显示标签 |
| 资产 | 源图哈希、经纬朝向、接缝、极区、日夜面、环背光、缺测标识 | 逐个天体1440p特写并人工开图；版权不明/投影不明不入库 |
| 小行星 | 命名样本轨道、数据来源、统计模型分布/共振证据、确定种子 | 真实与示意分层；不以粒子密度冒充实际密度 |
| 实验 | 二体解析解、步长h/h2/h4收敛、长期能量与角动量监测 | 预期二阶全局误差比约4；给测试时长和步长，发散告警；第6期冻结具体预算 |
| 工程/性能 | Chrome与Edge，1080p/1440p/4K；帧时间P50/P95、内存/泄漏、上下文丢失、离线/损坏缓存 | 指明设备/驱动/浏览器与场景；正式负载才可报告60 FPS是否达标 |

上述数值是项目验收预算，不是 NASA/JPL 官方精度，也不是已通过结果。初期产品可用时间窗口计划 2000–2030，只有实际下载并验证完整目标覆盖交集后才开放；本期不承诺该窗口已可用。
