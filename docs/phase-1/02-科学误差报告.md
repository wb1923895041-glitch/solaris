## 方法与复现

1. `.venv-phase1/Scripts/python.exe scripts/build-ephemeris.py`：九个本体中心、统一SSB/ICRF/TDB/km/km/s；保留原始网格与独立TLIST回包。
2. `npm run check:science`：读取实际F64文件与原始留出数据；核对哈希，计算每目标/每时刻的误差，写出本报告所用JSON。
3. 浏览器另对四个UTC日期的九个目标直接与留出状态比较，完整结果见Chrome/Edge浏览器JSON。

另有 14 组科学行为检查，覆盖目录溯源、时标/日期、暂停/倍率、边界、来源不一致、科学映射和CPU相机相对减法。真实日志：[science-log](science-log.txt)。

未来闰秒、姿态与光度模型尚非本期精度保证范围。轨迹显示折线只用于视觉，不代替连续状态误差验证；本期无轨道外推或随机轨道回退。
