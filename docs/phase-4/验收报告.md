# SOLARIS 第 4 期：小行星带、矮行星与外围区域

恢复点：`da9c649`（第 3 期终验）。本期新增 `src/smallbodies/`（命名小天体星历、GPU 统计层、命名层、局部视图母体、控制器）与第 4 期数据脚本；主场景增加外部天体聚焦接口。

## 数据与来源
- **命名天体（14 个）**：JPL Horizons 太阳系质心矢量（ICRF / TDB / km），卡戎以冥王星本体中心 999 为原点；原始回包、查询参数与 SHA-256 归档于 `data/phase-4/raw/`。物理参数来自 JPL SBDB（全精度）与 Horizons 天体数据头。
- **统计层**：JPL SBDB 查询——已编号小行星 H&lt;15、a&lt;5.5 au，共 74,597 个（含 Hilda 与木星特洛伊）；已登记海王星外天体 8,306 个。运行文件只保留真实密切根数，不含个体身份（第 0 期 `illustrative-population` 规则），在 GPU 上按开普勒方程二体传播，界面明示“不作定位用途”。
