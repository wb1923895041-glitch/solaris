# SOLARIS 第 7 期：视觉打磨与性能

- 画质档位（`src/render/quality.ts`）：自动 / 高 / 标准 / 节能，只改变 WebGL 绘制缓冲像素比，所有视图共用；自动档按 90 分位帧时间升降并记录每次切换。
- 日月食扫描移入 Web Worker；统计层 8.3 万样本为单次绘制的 GPU 点精灵（顶点着色器解开普勒方程）；局部系统浮动原点、对数深度、标签避让、过渡绕行星且出轨道面。
- 不使用全局 Bloom；太阳边缘光与 Titan 雾霾为有出处的物理近似，不加装饰性炫光。

## 木星、天王星、海王星环系（新增）
数据：NASA NSSDCA 行星环资料表（归档并校验 SHA-256），共 22 条环带；海王星 Adams 环弧因资料无经度而不定位，推定值逐项标注（`data/phase-7/minor-rings.json`）。渲染：亮度 ∝ 法向光学厚度 × 反照率；比像素窄的环按像素宽度绘制并等比降低亮度（积分亮度守恒）；计算行星对环的阴影。默认“增强”显示每颗行星单独增益并在界面披露（599 ×1.6e+06, 799 ×4.76, 899 ×145），窄而致密的环保留最小可见线；关闭增强即为真实相对亮度——木星环此时约 1.5×10⁻⁷ 不透明度，几乎不可见，这是真实情况。验证 `scripts/verify-minor-rings.mjs` 7 项通过。
